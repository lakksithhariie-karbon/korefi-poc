# Documented reasons for app-vs-POS order mismatches

Researched 24 Nov 2026. Public help centres and merchant docs only. No logins, no merchant portals.

**What this is for.** When the recon agent finds a mismatch between a delivery app report (DoorDash, Uber Eats, Grubhub) and the POS (Toast, Square, Clover), it may only name reasons from this list. Each reason has a public source.

**How to read the confidence column**
- **Documented**: the page says it plainly, and we read the page directly.
- **Documented (index)**: the page says it, but the site blocks automated reading (HTTP 403). We saw the text only through the search engine's copy of the page. Before showing this to customers, open the link in a normal browser and check it. This applies to **all help.doordash.com, merchants.doordash.com and developer.doordash.com pages**, the Otter help desk, the Grubhub developer portal, and some Clover help pages.
- **24 Nov 2026 live check:** the DoorDash rows marked "Documented (index)" were re-checked in a normal browser. Each now says whether the live page confirms it. DoorDash's cancelled-order page also lists "Long Fulfillment Time" as **not paid**.
- **Partly documented**: the page supports part of the reason, or we are combining two documented facts. The agent should word these as "may", not "is".

**General cautions**
- Unless marked, pages are for the **US**. Some pages exist in several country versions with different rules.
- Pages often disagree, and some are old. Conflicts are flagged in the rows.
- A quote is under 15 words. "Paraphrase" means we could not check the exact wording.
